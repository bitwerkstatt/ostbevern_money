<objective>
Close review warning WR-01 (bundled with CR-01 per the verifier's recommendation in 06-VERIFICATION.md "Gaps Summary") and make it verifiable without a browser (06-VERIFICATION.md `behavior_unverified_items`):

`MenueGruppe.positioniere()` resets the reactive offset to 0 and immediately measures the list. Vue has not re-rendered, so the measured rectangle still carries the previous inline `left`; on the second open (and on resize) no correction is computed and the list overflows the window edge again.

Fix: extract the computation into a pure, unit-tested function `listenVersatz()` that derives the base position from the measured rectangle minus the offset already applied and returns the absolute offset; `positioniere()` measures once and assigns its result.

Purpose: D-19 / UI-SPEC E12 overflow ("die Dropdown-Liste … überdeckt Inhalt und bleibt in 360 px nie breiter als der Viewport"); the four Phase-6 pages are reachable only through this group, so a clipped list hides their links.
Output: `app/src/lib/menueVersatz.ts` with tests, `MenueGruppe.vue` wired to it.
</objective>
